## Implementation evidence — 2026-09-19

The RedIsAlpha compatibility meaning was established from the repository's recorded VkDoom baseline and the existing cross-backend producer/consumer contract before changing Vulkan behavior. `CTF_IndexedRedIsAlpha` selects `Get8BitPixels(true)`, and image-backed textures implement that as luminance output; `TM_ALPHATEXTURE` is the fixed-colour `(1,1,1,r)` interpretation selected by `STYLEF_RedIsAlpha`. Ordinary indexed palette data is therefore a different R8 semantic and must not alias the RedIsAlpha resident image or descriptor identity.

The bounded Vulkan repair carries `mRedIsAlpha` in `FMaterialState` at the established `SetTextureMode`→`SetMaterial` boundary, gives RedIsAlpha its own cached R8 `VkTextureImage`, partitions material descriptor variants on the interpretation bit, and uploads both indexed forms as one byte per texel. The fragment path reads palette-mode RedIsAlpha from the R8 red component and excludes this fixed-colour alpha mode from ordinary palette-index alpha binarization and colormap lookup. Ordinary `CTF_Indexed`, translations, clamp/no-filter policy, layer ordering and PF-003 bindless allocation/free semantics are otherwise unchanged.

The GGX repair rewrites the inherited denominator from the cancellation-prone `1 + NdotH^2 * (a^2 - 1)` form to the algebraically equivalent `(1 - NdotH^2) + NdotH^2 * a^2` form and returns the finite sampled-BRDF limit `0` for exactly zero lobe width. No PF-011 calibration constants or normal material parameters were changed. The adversarial fixture covers exact zero, epsilon roughness and ordinary roughness equivalence.

The sprite precache marking path now passes the `scaleflags` word it already computes to `FMaterial::ValidateTexture`, preserving `CTF_Expand` and optional `CTF_Upscale` identity instead of collapsing the request to boolean `true`.

Immediate adjacent audit results: the helper `PrecacheSprite` and wall/flat marking path already pass their computed scale flags correctly; both synchronous and asynchronous Vulkan texture-creation branches shared the same RedIsAlpha format-classification defect and are repaired together; descriptor cleanup still frees every bindless slot before clearing material variants; no second GGX denominator singularity requiring a separate repair was found in the touched PBR path. No materially separate defect from this bounded audit requires a new issue.

Acceptance remains pending the exact implementation head passing the deterministic PF oracle, compiled adversarial/source-contract coverage and inherited Windows/macOS/Linux build matrix, followed by merge verification on `master` and final execution-ledger reconciliation.
