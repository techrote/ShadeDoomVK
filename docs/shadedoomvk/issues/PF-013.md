# PF-013 — Texture/material correctness repair pack

## Objective

Repair the confirmed texture/material correctness defects identified by the deep baseline audit after PF-003/PF-008 stabilize descriptor and material semantics.

## Scope / required work

- Add a failing fixture for Vulkan palette/indexed rendering requiring `CTF_IndexedRedIsAlpha`; implement the missing handling without regressing ordinary indexed/palette translations.
- Add numerical/visual fixtures for PBR roughness exactly/near zero and make GGX evaluation finite/stable while preserving normal roughness behavior.
- Fix the sprite precache/material-marking path that computes `scaleflags` but passes a boolean literal to `FMaterial::ValidateTexture`; preserve intended `CTF_Expand`/upscale variant identity.
- Audit immediately adjacent material/texture code touched by these fixes for the same source-proven class of defect; record materially separate findings rather than expanding scope without evidence.
- Ensure PF-002/PF-003 generation/descriptor semantics remain correct when material variants are recreated.

## Non-goals

- No new height/POM semantics.
- No broad texture-manager cleanup or performance optimization.
- No PBR calibration/aesthetic retune beyond numerical safety at the defective edge.
- No unrelated precache policy change.

## Dependencies

- RedIsAlpha indexed fixture follows the intended alpha semantics on Vulkan while ordinary indexed translations remain correct.
- PBR roughness-zero fixture produces finite stable values/no NaN/Inf and ordinary roughness images remain equivalent.
- Sprite precache creates/marks the intended material variant flags including expand/upscale cases.
- No stale descriptor/material reference appears during recreate/precache stress.
- Required CI passes; PR merged and verified.

## Verification

## Expected artifacts

## Blocking / stopping conditions
