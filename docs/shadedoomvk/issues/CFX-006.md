# CFX-006 — Bounded fault-query and upload/descriptor identity capture

## Objective
Resolve the capture ambiguities identified by accepted #79/#92: distinguish empty/error/unavailable device-fault and checkpoint queries, and correlate LevelMesh packed upload fingerprints, buffer lifetime, descriptor writes/generations and pipeline creation inputs with the existing run/command/submission timeline.

## Scope / required work
Use existing opt-in CFX trace and manifest. Log EXT query status, requested/returned counts and bounded truncation; NV void-query count/read evidence without inventing a VkResult. Add renderer-local allocation identities for buffers, sets and command buffers, retirement and copy ranges, bounded packed LevelMesh fingerprints, PF generation tokens and complete pipeline creation keys. Provide offline injected-query and resource/timeline fixtures, Windows compilation, operator interpretation and limitations.

## Non-goals
No crash repair, renderer synchronization/descriptor/upload semantic change, GPU launch, new physical budget, Aftermath/driver/system-policy change, proprietary content or general observability framework. Fingerprints do not prove GPU visibility or shader execution.

- Diagnostics disabled does no new hashing/query/trace work; renderer calls/data/order unchanged.
- Positive/adversarial offline tests and Windows compilation; clear artifacts/operator procedure; parent #75 capability update.
- Reviewed PR with required CI green before merge/closure. No physical validation claim.
