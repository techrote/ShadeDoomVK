# PF-014 — Sprite/portal state correctness repair pack

## Objective

Repair the confirmed sprite/portal-state correctness defects from the audit after PF-009/PF-010 establish explicit sprite orientation and render-context contracts.

## Scope / required work

- Preserve/reproduce the sprite ceiling-clip sentinel defect in `HWSprite::PerformSpriteClipAdjustment`; fix the `top` sentinel/fallback logic with targeted floor/ceiling/3D-floor fixtures.
- Replace `HWSkyInfo` raw `memcmp` equality with semantic field equality/hash/comparison that cannot be influenced by object padding, while preserving sky identity/dedup behavior.
- Audit the PF-009/PF-010 extraction boundaries for directly adjacent mirror/portal state defects revealed by fixtures; fix only source-proven/reproduced issues and file materially separate findings independently.
- Ensure mirror/plane-mirror handedness, portal recursion and sprite visibility/frame state remain compatible.
- Preserve image/state equivalence outside the assigned fixes.
