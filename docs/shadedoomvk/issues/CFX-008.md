## Objective

Identify which reported Vulkan object bind/unbind histories overlap the new DBP37 MAP01 GPU fault interval. Use the result to localize a source-level index/range, descriptor/resource lifetime or pipeline hypothesis and the smallest justified repair. Address overlap is not itself proof of root cause.

## Authorization and finite protocol

The owner approved the documented proposal with “Go ahead!” after being told the existing 16-launch/6-loss ceiling is spent. This new scope permits **at most two application launches including the safe control, and one confirmed device-loss/TDR episode**. App loss and its correlated OS TDR count once. No blind repeated target or candidate-repair validation is included. Routine human visual confirmation is waived under the existing unattended automatic recovery authorization; observed corruption still stops.

Historical CFX-003/005/007 STOP guards, source/runtime and exhausted counts remain immutable. Use a new evidence root and a new merged-PR98 EXE/PDB; do not relabel/reopen an old physical lane. No driver/TDR/clocks/power/BIOS change, broad GPU stress, quality reduction as a fix, global idle or arbitrary traversal cutoff.
