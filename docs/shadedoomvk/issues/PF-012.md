# PF-012 — Probe/lightmap correctness and spatial-selection repair

## Objective

Turn the inherited lightmap/probe plumbing from a mixture of working and partial paths into a truthful, bounded foundation: repair confirmed probe-placement/selection defects, qualify or explicitly defer incomplete AABB/probe-map machinery, and make fallback/index/lifetime behavior deterministic.

## Scope / required work

- Preserve/reproduce the baseline per-lightmap probe-map failure where `frag_copy.glsl` selects a `findClosestProbe()` stub returning probe 0.
- Define the intended per-lightmap probe-selection contract before implementation. Do not simply flip the preprocessor branch; audit/fix the disabled traversal or implement a clearer equivalent.
- Fix automatic sector probe placement Z midpoint arithmetic and add non-zero-floor fixtures.
- Audit `LightProbeAABBTree` construction/query plus empty `Update()`/`Upload()` functions; either complete the integration required by the selected probe-map design or explicitly remove/defer unused assumptions with tests/documentation.
- Test `LightProbeIncrementalBuilder::Step`/`Full` completion/progress behavior, including a completed/terminal builder state; fix any non-progress edge reproduced.
- Make probe index 0/fallback semantics explicit across sector/side targets, bindless environment probe pairs and lightmap probe maps.
- Validate atlas-page/probe-map descriptor bounds and PF-002/PF-003 lifetime generations through reset/rebake/reload.
- Preserve no-probe and ray-query-disabled fallbacks.

## Non-goals

- Do not tune probe density/blending for aesthetics beyond what is required for correct selection.
- Do not implement actor environment-lighting policy owned by SDVK-010.
- Do not run the full integrated lightmapper robustness campaign owned by SDVK-014.
- Do not change PBR lighting calibration.

## Dependencies

PF-003, PF-004, PF-010, PF-011.

## Concurrency guidance

May overlap PF-013 and PF-014. Coordinate with PF-015 if shared LevelMesh visibility generations change. Do not begin before descriptor reservation/lifetime, view and LevelMesh contracts are merged.

## Required context

Read `AGENTS.md`, PF dependency evidence, `rag/02-RENDERER-IDENTITY-LIFETIME.md`, `rag/03-LEVELMESH-MUTATION-MATRIX.md`, `rag/06-LIGHTMAP-PROBE-PIPELINE.md`, `rag/07-PORTAL-COORDINATE-SPACES.md`, the known-traps reference and current probe/lightmapper shader/source.

## Autonomous implementation prompt

Complete PF-012 autonomously. Start with the failing probe fixtures; define expected selection/fallback semantics; repair the stub/incomplete path or explicitly bound it; fix automatic placement and any reproduced builder-progress defect; stress reset/rebake/page identity; preserve unrelated lighting output. Dedicated branch → tests/evidence/docs → PR → required checks → merge → verify `master` → RAG/ledger → close only when every assigned defect is fixed or proven superseded.

## Acceptance criteria

- A two-or-more-probe lightmap fixture no longer collapses every texel to probe 0 unless probe 0 is genuinely the expected selection.
- Auto-added probe Z is the intended vertical midpoint for non-zero-floor sectors.
- AABB/probe-map implementation status is truthful and tested; no dormant code is described as active.
- Probe builder full/incremental paths terminate/progress correctly in tested states.
- Probe 0/fallback and descriptor/page bounds are explicit and safe across reset/rebake.
- No-probe and unsupported optional-feature fallback works.
- Required CI passes; PR merged and verified.

## Verification

Use explicit and auto probes, non-zero floors, at least two spatial probes on a lightmapped surface, sector/side assignments, probe reset/rebake, multi-page lightmap/probe resources, completed-builder invocation, no-probe fallback and PF image/state diagnostics.

## Expected artifacts

Corrected probe/lightmap selection/placement code or explicit bounded fallback; minimized regression fixtures; lifetime/bounds tests; updated probe/identity/LevelMesh RAG; evidence/ledger entry.

## Blocking / stopping conditions

Stop if the intended per-texel selection semantics cannot be established from source/history and current renderer needs; create/record the precise decision blocker and keep a safe explicit fallback rather than enabling unfinished traversal. Do not guess at probe interpolation policy.
