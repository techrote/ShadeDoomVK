## Objective

- Preserve no-probe and ray-query-disabled fallbacks.

## Resolved implementation contract

Source tracing established the exact producer/consumer semantics before enabling selection:

- `lightmodel_pbr.glsl` consumes the `R16_UINT` lightmap probe texel directly as the irradiance `cubeTextures[]` descriptor index and consumes the next descriptor as the paired prefilter map.
- Probe-map value `0` is the explicit default/no-probe fallback.
- Authored probe ordinals are **not** descriptor indices and are **not** mapped by fixed arithmetic. `VkDescriptorSetManager::GetLightProbeTextureIndex(probe.index)` dynamically allocates/returns a two-slot bindless block: the returned slot is irradiance and `slot+1` is prefilter. The lightmap copy path must store that runtime-returned slot.
- If probe cubemaps are not yet available, `GetLightProbeTextureIndex()` returns fallback `0`; the candidate is omitted until a live pair exists. Runtime descriptor indices outside the `R16_UINT` range are omitted rather than truncated.
- The inherited disabled selection radius is 512 world units. PF-012 keeps that radius, makes the boundary inclusive and uses deterministic first-entry tie behavior.
- The active correctness path is a bounded linear nearest-probe search over live probe positions in the lightmap copy shader. The unfinished GPU AABB traversal is **not** enabled; its CPU construction/query defects are repaired, while `Update()`/`Upload()` remain explicitly dormant.
- Lightmap tile inverse transforms and `LightProbe::position` already share LevelMesh XYZ world coordinates for this copy pass. The raytrace-only Y/Z swap is not applied to the selector.
- Runtime probe placement invalidates existing per-texel probe mappings by marking lightmap tiles dirty and advancing the `LightmapProbe` mutation domain.
- Lightmap copy validates atlas page identity against both current CPU page metadata and current Vulkan page resources before dereference; mapped tile-copy writes are bounds-checked.
- `LightProbeIncrementalBuilder` terminates safely when complete, resets on probe-count changes including transition to zero, and `Full()` has an explicit no-progress guard.
- The selector is independent of Vulkan ray-query availability; the inherited ray-query-disabled baking fallback remains intact.

A pre-merge review caught and corrected an initially drafted but false `2*N+1` assumption before acceptance: the live producer is the dynamic PF-003 bindless allocator, not an ordinal-derived table. The source-contract suite now pins `AllocBindlessSlot(2)`, `bindIndex`/`bindIndex+1` producer semantics and the lightmapper's call to `GetLightProbeTextureIndex()` so that this distinction cannot silently regress.

- Required CI passes; PR merged and verified.
