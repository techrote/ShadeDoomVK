# PF-012 — Probe/lightmap correctness and spatial-selection repair

## Objective

Turn the inherited lightmap/probe plumbing from a mixture of working and partial paths into a truthful, bounded foundation: repair confirmed probe-placement/selection defects, qualify or explicitly defer incomplete AABB/probe-map machinery, and make fallback/index/lifetime behavior deterministic.

## Scope / required work

- Preserve/reproduce the baseline per-lightmap probe-map failure where `frag_copy.glsl` selects a `findClosestProbe()` stub returning probe 0.
- Define the intended per-lightmap probe-selection contract before implementation. Do not simply flip the preprocessor branch; audit/fix the disabled traversal or implement a clearer equivalent.
- Fix automatic sector probe placement Z midpoint arithmetic and add non-zero-floor fixtures.
- Audit `LightProbeAABBTree` construction/query plus empty `Update()`/`Upload()` functions; either complete the integration required by the selected probe-map design or explicitly remove/defer unused assumptions with tests/documentation.
- Test `LightProbeIncrementalBuilder::Step`/`Full` completion/progress behavior, including a completed/terminal builder state; fix any non-progress edge reproduced.
- Make probe index 0/fallback semantics explicit across sector/side targets, bindless environment probe pairs and lightmap probe maps.
- Validate atlas-page/probe-map descriptor bounds and PF-002/PF-003 lifetime generations through reset/rebake/reload.
- Preserve no-probe and ray-query-disabled fallbacks.

## Resolved implementation contract

Source tracing established the exact inherited consumer semantics before enabling selection:

- `lightmodel_pbr.glsl` consumes the `R16_UINT` lightmap probe texel directly as the irradiance `cubeTextures[]` descriptor index and consumes the next index as the paired prefilter map.
- Probe-map value `0` is the explicit default/no-probe fallback; authored probe ordinal `N` therefore maps to irradiance descriptor `2*N+1`, not to stored value `N`.
- The inherited disabled selection radius is 512 world units. PF-012 keeps that radius, makes the boundary inclusive and uses deterministic first-entry tie behavior.
- The active correctness path is a bounded linear nearest-probe search over live probe positions in the lightmap copy shader. The unfinished GPU AABB traversal is **not** enabled; its CPU construction/query defects are repaired, while `Update()`/`Upload()` remain explicitly dormant.
- Lightmap tile inverse transforms and `LightProbe::position` already share LevelMesh XYZ world coordinates for this copy pass. The raytrace-only Y/Z swap is not applied to the selector.
- The `R16_UINT` representation bounds the maximum authored ordinal to 32767 / stored irradiance descriptor 65535. Invalid identities fail to fallback rather than truncate.
- Runtime probe placement invalidates existing per-texel probe mappings by marking lightmap tiles dirty and advancing the `LightmapProbe` mutation domain.
- Lightmap copy validates atlas page identity against both current CPU page metadata and current Vulkan page resources before dereference; mapped tile-copy writes are bounds-checked.
- `LightProbeIncrementalBuilder` terminates safely when complete, resets on probe-count changes including transition to zero, and `Full()` has an explicit no-progress guard.
- The selector is independent of Vulkan ray-query availability; the inherited ray-query-disabled baking fallback remains intact.

Acceptance is still contingent on the exact implementation head passing the required PF oracle plus inherited Windows/macOS/Linux CI matrix, merge verification on `master`, and final ledger reconciliation.

## Acceptance criteria

- A two-or-more-probe lightmap fixture no longer collapses every texel to probe 0 unless probe 0 is genuinely the expected selection.
- Auto-added probe Z is the intended vertical midpoint for non-zero-floor sectors.
- AABB/probe-map implementation status is truthful and tested; no dormant code is described as active.
- Probe builder full/incremental paths terminate/progress correctly in tested states.
- Probe 0/fallback and descriptor/page bounds are explicit and safe across reset/rebake.
- No-probe and unsupported optional-feature fallback works.
- Required CI passes; PR merged and verified.

## Verification

Use explicit and auto probes, non-zero floors, at least two spatial probes on a lightmapped surface, sector/side assignments, probe reset/rebake, multi-page lightmap/probe resources, completed-builder invocation, no-probe fallback and PF image/state diagnostics.

The automated PF-012 suite combines a compiled pure selector fixture with source-route contract checks. It covers `2*N+1` descriptor encoding boundaries, the two-probe collapse regression, exact/just-outside 512-unit radius, stable ties, zero/out-of-range fallback, copy-pipeline descriptor/push-constant wiring, runtime probe invalidation, page/copy-buffer bounds, automatic midpoint arithmetic, builder terminal/empty-state guards and explicit AABB dormancy.
